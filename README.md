# pGerind

A later revision of my early React portfolio (see [portfolio-site](https://github.com/GerindT/portfolio-site)), adapted from Dorota Gil's [react-frontend-dev-portfolio](https://github.com/dorota1997/react-frontend-dev-portfolio) template, with an updated project list. Archived: superseded by my current portfolio, and the old demo is no longer hosted.

## Features

- About, projects, skills and experience sections, with project details in a modal
- Two-language content loaded from `public/res_primaryLanguage.json` and `public/res_secondaryLanguage.json`
- Light / dark theme toggle

## Stack

- React 16 (Create React App) with SCSS
- React Bootstrap, react-awesome-slider, react-vertical-timeline-component

## Run locally

```sh
npm install
npm start
```

The dependencies (`react-scripts` 3, `node-sass` 4) are old and may need an older Node version to install.
